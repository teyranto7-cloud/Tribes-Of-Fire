# Downloads — Tribes of Fire

Criado por **felipealx**. Entrega atual: [0.7.0-dev](0.7.0-dev/).

- Windows: execute o instalador `Windows-Setup.exe` ou extraia `Windows.zip`.
- Linux: extraia `Linux.zip`, permita executar e abra `TribesOfFire.x86_64`.
- Servidor dedicado: extraia `Server-Linux.zip` e siga as instruções incluídas.
- O ZIP `Source.zip` contém os arquivos reais do projeto e exige Godot para edição.

O editor não é necessário nos pacotes executáveis. Confira `SHA256SUMS.txt` e
`manifest.json` da versão. Entregas antigas permanecem nas suas pastas.
Estado e limitações: [README](../README.md) e [verificação](../Docs/DELIVERY_0.7.md).
